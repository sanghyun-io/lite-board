# lite-board

브라우저에서 바로 쓰는 아주 가벼운 무한 캔버스 화이트보드입니다. `index.html` 파일 하나(바닐라 JS + SVG)로 동작하며 외부 의존성과 빌드 단계가 없습니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 작업 내용은 localStorage에 자동 저장되고 새로고침하면 복원됩니다.

## 단축키

|---|---|

| `A` `L` `T` `N` | 화살표 / 선 / 텍스트 / 노트 |
| `R` `O` | 사각형 / 타원 |
| 휠, Space+드래그, 가운데 버튼 | 캔버스 이동 |
| Ctrl/⌘+휠, 핀치 | 줌 |
| `+` `-` `0` `Shift+1` | 확대 / 축소 / 100% / 전체 맞춤 |
| Shift+클릭, 빈 곳 드래그 | 다중 선택 / 마퀴 선택 |
| 더블클릭, `Enter` | 텍스트·노트·도형 라벨 편집 (빈 곳 더블클릭은 새 텍스트) |
| `Delete` / `Backspace` | 삭제 |
| `Ctrl+D` / `Ctrl+A` | 복제 / 전체 선택 |

| `Ctrl+Z` / `Ctrl+Shift+Z`, `Ctrl+Y` | 실행취소 / 다시실행 |

| `Esc` | 선택 해제 / 선택 도구로 |

| 탭에 포커스 후 `←` `→` `Home` `End` / `F2` / `Delete` | 페이지 이동 / 이름 변경 / 페이지 삭제 |

리사이즈 중 Shift는 비율 유지, 사각형·타원 생성 중 Shift는 정사각형·원, 화살표·선 생성 중 Shift는 15° 단위 스냅입니다.

## 페이지(시트 탭)

문서 하나에 페이지를 여러 장 둘 수 있습니다. 화면 아래쪽, 실행취소·줌 버튼 오른쪽에 엑셀 시트처럼 페이지 탭이 있습니다.

- 탭 클릭: 그 페이지로 이동. 페이지마다 화면 위치·줌(카메라)을 따로 기억합니다. 이동할 때 열려 있던 텍스트 편집은 확정되고 선택은 해제됩니다.
- **`+`**: 새 페이지(`Page N`, 쓰이지 않은 다음 번호)를 끝에 추가하고 그 페이지로 이동합니다.
- 탭 더블클릭: 이름 변경. `Enter` 또는 다른 곳 클릭으로 확정, `Esc`로 취소. 빈 이름은 거부합니다.
- 탭의 `×`(마우스를 올리거나 현재 탭일 때 보임): 페이지 삭제. 마지막 한 장은 삭제할 수 없습니다.
- 탭을 좌우로 끌어 순서를 바꿉니다. 탭이 많으면 탭 줄이 가로로 스크롤됩니다(휠도 가능).
- 페이지 추가·삭제·이름 변경·순서 변경은 모두 `Ctrl+Z`로 되돌릴 수 있습니다. 다른 페이지에서 한 도형 편집을 되돌리면 그 페이지로 이동합니다. 페이지 이동 자체는 실행취소 단계가 아닙니다.
- 도구, 선택, 지우개, 맞춤(`Shift+1`), 빈 보드 안내, 복사/붙여넣기는 현재 페이지 기준입니다(복사한 도형은 다른 페이지에 붙여넣을 수 있음).

## 내보내기

- **`.liteboard`** (`board.liteboard`): 자체 포맷 v2. 내용은 JSON이고 MIME은 `application/vnd.liteboard+json`입니다. 모든 페이지를 담습니다.
  ```json
  { "app": "lite-board", "version": 2, "current": "p_main",
    "pages": [ { "id": "p_main", "name": "Page 1", "camera": {"x":0,"y":0,"z":1},
                 "shapes": [ {"id":"s_1","type":"rect","x":0,"y":0,"w":100,"h":80,"text":"",
                              "style":{"color":"black","fill":"none","dash":"draw","size":"m"}} ] } ] }
  ```
  `pages` 배열 순서가 탭 순서이고 `current`는 열려 있던 페이지의 `id`입니다. `camera`가 `null`이면 처음 열 때 전체 맞춤을 합니다. 이전 v1 파일(`{"version":1,"camera":…,"shapes":[…]}`)도 그대로 열 수 있으며 `Page 1` 한 장으로 읽습니다. 그 밖의 버전은 오류 토스트로 거부합니다. 자동 저장(localStorage `lite-board:v1` 키)도 v2로 저장하며, 기존 v1 값은 처음 불러올 때 자동으로 변환합니다(원본은 `lite-board:v1:v1-backup`에 백업).
  도형의 `type`은 `rect | ellipse | note | text`(x, y, w, h), `draw`(`points`: **페이지 좌표 절대값** `[[x,y],...]`), `arrow | line`(`start`, `end` 페이지 좌표)입니다. 텍스트에 `"wrap": true`가 있으면 너비 고정 줄바꿈입니다. 배열 순서가 그리는 순서입니다.
- **`.tldr`** (`board.tldr`): tldraw에서 열 수 있는 파일. tldraw.com에서 저장한 실제 파일의 스키마(`schemaVersion: 2`)와 레코드 형식을 따릅니다. 사각형·타원은 `geo`, 텍스트는 `text`, 노트는 `note`, 화살표는 `arrow`, 선·다각선은 `line`, 손그림은 `draw`(base64 float16 경로)로 저장합니다. 글꼴은 `sans`로 지정합니다. 모든 페이지를 `page:1`, `page:2` … 페이지 레코드로 내보내고 도형은 각자의 페이지에 둡니다(선택이 있으면 선택한 도형만 한 페이지로). tldraw.com에서는 파일을 캔버스에 끌어다 놓으면 열립니다.
- **SVG**: 현재 페이지의 전체 도형(선택이 있으면 선택한 도형만), 여백과 흰 배경 포함.
- **PNG**: 위 SVG를 2배율로 래스터라이즈.

## 링크로 공유

상단 메뉴의 **Share**를 누르면 모든 페이지를 포함한 보드 전체(v2)를 압축(deflate)해 URL의 `#b=` 뒤에 담은 링크가 클립보드에 복사됩니다. 서버나 DB에 아무것도 저장하지 않으며, `#` 뒤 내용은 브라우저가 서버로 보내지 않습니다.

- 링크를 연 사람은 그 시점의 보드를 받아 자기 브라우저에서 이어서 편집할 수 있습니다(원본은 바뀌지 않음, 실시간 공동 편집 아님).
- 이전 버전에서 만든 v1 링크(페이지 한 장)도 열 수 있습니다.
- 링크를 열면 기존 보드는 `Ctrl+Z`로 되돌릴 수 있고, `localStorage`의 `lite-board:v1:before-share`에도 백업됩니다.
- 도형 14개짜리 샘플 보드가 약 800자입니다. 링크가 32KB를 넘으면 일부 메신저에서 잘릴 수 있다고 안내합니다.

## 가져오기

상단 메뉴의 **Open** 버튼으로 파일을 고르거나 캔버스에 파일을 끌어다 놓습니다. 가져오기는 현재 문서를 대체하며 `Ctrl+Z`로 되돌릴 수 있습니다.

- `.liteboard`: 자체 포맷 v1·v2(하위 호환으로 `.json`도 열 수 있음). 가져온 뒤에는 현재 페이지의 도형이 화면의 약 75%를 차지하도록 여유 있게 맞춥니다(100%보다 크게 확대하지는 않음). 공유 링크를 열 때도 같습니다. `Shift+1`과 맞춤 버튼은 지금처럼 꽉 맞춥니다.
- `.tldr`: 상호운용을 위한 **부분 지원(subset)**입니다. **모든 페이지**를 `index` 순서대로 가져와 페이지 이름을 유지하고, 도형은 최상위 부모 페이지별로 나눕니다. 토스트에 가져온 페이지·도형 수와 건너뛴 수를 표시합니다. 도형은 `geo`(타원 계열은 ellipse, 그 외는 rect), `text`, `note`, `arrow`(바인딩·bend 무시), `line`(2점은 line, 3점 이상은 draw), `draw`/`highlight`를 변환합니다. 그룹·프레임 안의 도형은 페이지 좌표로 옮기고, 회전은 무시합니다. 이미지·프레임 등 지원하지 않는 도형은 건너뛰고 개수를 토스트로 알려줍니다.

예제 파일은 `samples/` 폴더에 있습니다(`sample.liteboard`는 `Page 1`, `Ideas` 두 페이지짜리 v2 파일).

## 스크립트 / AI 에이전트용 API

페이지가 `window.liteBoard` 객체를 공개합니다. Playwright나 AI 에이전트의 브라우저 도구처럼 페이지에서 JavaScript를 실행할 수 있으면, 클릭 없이 도형·페이지를 읽고 추가·수정하고 SVG/PNG/공유 링크로 내보낼 수 있습니다. 호출 하나가 실행취소 한 단계이고, 잘못된 입력은 이유를 담은 오류로 거부합니다. 자세한 내용은 [API.md](API.md)를 보세요.

```js
await page.evaluate(() => liteBoard.addShape({ type: "note", x: 0, y: 0, text: "할 일" }));
```

## 브라우저 없이 보드 만들기 (SDK · CLI · MCP)

[`sdk/`](sdk/README.md)는 브라우저 없이 앱의 기능을 모두 씁니다. 보드를 만들고 고치고(페이지, 도형, 복제·붙여넣기, 실행취소), 공유 링크·`.liteboard`·`.tldr`·SVG·PNG로 내보내고, 링크·`.liteboard`·`.tldr`를 읽습니다. 서버는 필요 없습니다. 같은 폴더에 AI 에이전트용 MCP 서버(`node sdk/cli.mjs mcp`)도 있어서, 에이전트가 "다이어그램 그려줘"라는 요청에 보드 링크나 파일로 답할 수 있습니다.

## 고지

lite-board는 독립적으로 만든 프로젝트이며 tldraw와 아무 관련이 없습니다(제휴·후원·승인 관계 없음). "tldraw"는 해당 소유자의 상표이며, `.tldr` 가져오기는 파일 호환을 위한 기능일 뿐입니다.
